## ✨ Основные возможности

- 🎛️ **Студийный аудиодвижок и DSP**:
  - **10-полосный эквалайзер**: аппаратная обработка полос от 31 Гц до 16 кГц.
  - **16 откалиброванных пресетов**: Flat, Bass Boost, Vocal, Rock, Pop, Electronic, Jazz, Acoustic, Classical, Night, Gym, Car, AirPods Pro, Sony WH-1000XM4/5, Sennheiser HD600, а также сохранение собственных пресетов.
  - **Усиление баса (Bass Boost) и Виртуализатор**: пространственное расширение стереопанорамы и плотный саб-бас.
  - **True-Peak Headroom Guard**: динамический запас по перегрузке для предотвращения интерсэмплового клиппинга и искажений ЦАП.
  - **Equal-Power Crossfade**: кроссфейд постоянной акустической энергии ($\cos^2 + \sin^2 \equiv 1$) без провалов в громкости.
  - **Smart Album Gapless**: умное определение последовательных треков альбома для идеального бесшовного воспроизведения (gapless).
  - **Нормализация громкости**: сглаживание перепадов уровней между различными источниками треков.

- 🎙️ **Распознавание музыки (Shazam)**:
  - Мгновенный поиск играющей вокруг музыки через акустические отпечатки на чистом Dart (БПФ Radix-2 и выделение спектральных пиков).
  - Нативный захват звука с микрофона в реальном времени (`bloom/recognition`).
  - Анимированный радар с волнами прослушивания и локальная история распознаваний.

- 🎤 **Караоке и синхронизированные тексты песен**:
  - **Послоговое караоке**: поддержка формата TTML с таймингами отдельных слов и шейдерной маской подсветки.
  - **Универсальный пул зеркал**: автоматический перебор источников (зеркала LyricsPlus, прямой endpoint Яндекс Музыки `/tracks/{id}/supplement`, Musixmatch, Spotify).
  - **Автоматическая романизация**: транскрипция для корейского (хангыль), японского (кана -> латиница) и кириллицы.

- 🌐 **Единая медиатека и стриминг**:
  - SoundCloud, YouTube Music, Яндекс Музыка и локальные аудиофайлы.
  - Скробблинг в Last.fm и синхронизация управления с ПК (Connect Remote).

## 🚀 Разработка

```bash
flutter pub get

flutter run -d <device>
flutter test                  # юнит-тесты, математика DSP, распознавание и тексты
dart run tool/sc_smoke.dart   # живой smoke против api-v2 SoundCloud

flutter build apk --release   # android
flutter build ios --release   # ios, нужен macOS
```

Требуется [Flutter](https://docs.flutter.dev/get-started/install) 3.41+.
